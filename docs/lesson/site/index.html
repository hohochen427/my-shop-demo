果醬島開店課Jam Island Shop Class

拆解「HenHen日初」的 3D 果醬島與果醬商店，看它用了哪些技術、照什麼順序做出來，以及怎麼對 AI 下提示詞。內容根據兩個網站的原始碼與存檔紀錄整理。We take apart two real websites by HenHen日初: a 3D Jam Island and a jam shop. You will see which tools they use, the order they were built in, and how to give clear instructions (prompts) to AI. Everything here comes from the real code and save history.

圖二Diagram 2

和 AI 一起做網站的流程How to build a website with AI

這是整堂課最重要的一張圖。網站不是一句「幫我做電商網站」就完成的，而是先定規矩，再一次做一小件，每件都自己點過才存檔。This is the most important diagram in the lesson. You can't build a shop with one line like “Make me an online store.” Set the rules first. Then build one small thing at a time, and check each one yourself before you save.

課程路線Course paths

基礎班與進階班Basic class and advanced class

商店那一半要註冊 Neon、Vercel、GitHub、綠界等多個帳號，部分服務有年齡限制，金流概念對國中生也偏重。建議先做基礎班，進階班給高中或社團。The shop part needs accounts on Neon, Vercel, GitHub, and ECPay. Some have age limits, and online payments are a hard topic for junior high. Start with the basic class. The advanced class fits senior high or a club.

基礎班Basic我的 3D 小島商店My 3D island shop

  1. 寫自己的 CLAUDE.md 班規Write your own CLAUDE.md class rules
  2. 請 AI 規劃小島和檔案分工Ask AI to plan the island and the files
  3. 做出地形、建築、可旋轉的鏡頭Build the land, the buildings, and a camera you can turn
  4. 建立 JSON 商品資料，點建築跳出圖卡Make a JSON product file. Tap a building to show a card.
  5. 加「假購物車」：用瀏覽器本機儲存記住買了什麼，結帳只顯示「訂單完成」Add a pretend cart. The browser remembers what you bought, and checkout just says “Order complete.”
  6. 用 Netlify 拖曳上線，互相逛同學的島Go live with Netlify drag and drop, then visit your classmates' islands

需要瀏覽器、Python 和 AI 工具；雲端帳號只要 Netlify 一個。You need a browser, Python, and an AI tool. Only one online account: Netlify.

進階班Advanced真的能下單的店A shop with real orders

  1. 從範本商店開始，改成自己的店名與商品Start from the shop template. Change the name and the products.
  2. 連上 Neon 資料庫，跑 npm run db:setupConnect to the Neon database and run npm run db:setup
  3. 看懂圖三：為什麼錢要在後端算Understand Diagram 3: why money is calculated on the server
  4. 用 PRD → SDD → TASKS 的方式加一個功能（例如優惠碼）Add one feature with PRD → SDD → TASKS (for example, coupons)
  5. 寫檢查腳本，確認不會超賣Write a check script to make sure you never sell more than you have
  6. 部署到 Vercel，和基礎班的小島互連Put it on Vercel and link it to a basic-class island

需要 Node.js、Git、GitHub、Neon、Vercel 帳號。密碼一律由學生自己填，不貼給 AI。You need Node.js, Git, and accounts on GitHub, Neon, and Vercel. Students type passwords themselves and never paste them to AI.

提示詞範本Prompt templates

每一步怎麼對 AI 說What to say to AI at each step

正面是這一步要做的事，先讓學生自己寫一句提示詞，再翻面對照範本。好的提示詞有三個部分：要做什麼、限制是什麼、做完要怎麼回報。The front shows the task for this step. Let students write their own prompt first, then flip to compare with the template. A good prompt has three parts: what to do, the limits, and how to report back.

①

先定規矩Set the rules first

最重要Most important

規矩寫在檔案裡，AI 每次都會讀，不用每次重講。Rules saved in a file are read by the AI every time, so you don't have to repeat them.

先想想：你希望 AI 遵守哪四條規矩？Think: which four rules should the AI follow?

① 先定規矩・範本Template
中文範本
我要做一個賣果醬的模擬商店網站，給國中生學習用。請先幫我寫一份 CLAUDE.md 工作守則：
1. 用繁體中文回答，技術名詞第一次出現要用一句話解釋
2. 動手前先說要改哪些檔案，等我同意再做
3. 一次只做一件事，做完告訴我要在瀏覽器點哪裡檢查
4. 沒實際檢查過的，不可以說已經完成
English template
I want to build a pretend jam shop website for junior high students to learn with. First, write a CLAUDE.md file with these rules:
1. Answer in simple English. Explain each tech word the first time you use it.
2. Before you change anything, tell me which files you will change. Wait for my OK.
3. Do one thing at a time. When you finish, tell me where to click in the browser to check it.
4. Never say something is done if you haven't really checked it.
②

先規劃，不寫程式Plan first, no code yet

先看計畫再決定，比做完才發現方向錯省很多時間。Checking the plan first saves a lot of time. Finding out you went the wrong way after building everything is much worse.

先想想：要怎麼叫 AI「先別寫」，又要它告訴你什麼？Think: how do you tell AI “don't write code yet”? What should it tell you instead?

② 先規劃・範本Template
中文範本
我想做一座 3D 小島當商店入口，島上有工坊、廣場、果園，點建築會跳出果醬介紹。
先不要寫程式。請告訴我：需要哪些技術、檔案怎麼分、要分幾步做完。
限制：只用 HTML、CSS、JavaScript 和 Three.js，不要安裝任何套件。
English template
I want to make a 3D island as the entrance to my shop. The island has a workshop, a plaza, and an orchard. When you tap a building, a jam card pops up.
Don't write any code yet. Tell me which tools I need, how to split the files, and how many steps it will take.
Limits: use only HTML, CSS, JavaScript, and Three.js. Don't install any packages.
③

資料和程式分開Keep data and code apart

以後改商品文字只要改資料檔，不會不小心弄壞程式。Later you only edit the data file to change the text, so you won't break the code by accident.

先想想：一款果醬需要記下哪些資料？Think: what information does one jam need?

③ 資料和程式分開・範本Template
中文範本
請建立 content/jams.json，放 6 款果醬的名稱、產地、一句介紹、代表色。
網頁從這個檔案讀資料，之後我改文字就不用碰程式。
English template
Please create content/jams.json with 6 jams. For each jam, add its name, where it comes from, a one-line description, and a main color.
The web page should read from this file, so I can change the text without touching the code.
④

一次加一個功能Add one feature at a time

說清楚「現在只做這件」，並要求 AI 告訴你怎麼驗收。Say clearly “only this one thing now,” and ask AI how to check it.

先想想：做完之後，你要 AI 告訴你什麼？Think: when it's done, what should AI tell you?

④ 一次加一個功能・範本Template

出錯時給證據Give proof when something breaks

只說「壞了」，AI 只能猜。貼上完整錯誤訊息，它才知道問題在哪。If you only say “it's broken,” AI has to guess. Paste the full error message so it knows where the problem is.

先想想：除了「壞了」，還要告訴 AI 哪兩件事？Think: besides “it's broken,” what two things should you tell AI?

圖三・進階班Diagram 3 · Advanced

下單到付款，錢在哪裡算From order to payment: where is the money calculated?

客人的瀏覽器只送「買了哪幾樣、各幾罐」。價格、運費、折扣都由商店後端從資料庫重新算。訂單要等綠界送來付款通知，並確認簽章正確、沒處理過，才會變成「已確認」。The customer's browser only sends which items and how many jars. The shop's server looks up prices, shipping, and discounts in the database. An order becomes “confirmed” only after ECPay sends a payment notice, the signature is correct, and the notice hasn't been handled before.

和 AI 合作的五個好習慣Five good habits for working with AI

先規劃再寫Plan before you build
看過計畫才讓 AI 動手Let AI start only after you read the plan例：「先不要寫程式，告訴我要分幾步。」e.g. “Don't write code yet. Tell me how many steps it takes.”
一次一件事One thing at a time
小步做，壞了才找得到原因Small steps make problems easy to find例：這間店的優惠碼拆成 3 個存檔完成。e.g. This shop built its coupons in 3 separate saves.
自己點過才算完成It's done only after you check it
AI 說好了不等於真的好了When AI says “done,” it may still be broken例：驗收清單記下 31 項通過、1 項不通過、10 項未檢查。e.g. The test list recorded 31 passed, 1 failed, and 10 not checked yet.
錯誤訊息完整貼上Paste the whole error
給證據，不要讓 AI 猜Give proof so AI doesn't have to guess例：F12 主控台的紅字整段複製貼上。e.g. Copy all the red text from the F12 console.
密碼不給 AI、不上網Keep passwords away from AI and the internet
放在環境變數，自己填Put them in environment variables and type them yourself例：這間店設定成 AI 讀不到 .env.local。e.g. This shop is set up so AI can't read .env.local.
