Netlify基礎猜猜看：網站放在哪裡別人才看得到？

果醬商店

Next.js＋React進階猜猜看：客人頁面和店家後台怎麼放在一起？
同時做前台和後台的網站框架Next.js 16，客人頁面和店家後台在同一個專案
TypeScript進階猜猜看：它和 JavaScript 差在哪？
會幫你抓錯字的 JavaScript商店所有 .ts、.tsx 檔
Neon（PostgreSQL）進階猜猜看：訂單存在哪裡？
放在網路上的大型表格商品、訂單、付款、優惠碼各一張表
綠界測試環境進階猜猜看：練習刷卡會不會真的扣錢？
模擬刷卡，不會真的扣錢付款完成後由綠界通知商店改訂單狀態
Vercel進階猜猜看：改了程式怎麼自動更新網站？
放 Next.js 網站的平台和 GitHub 連動，推上去自動更新
環境變數進階猜猜看：資料庫密碼要放哪裡？
放密碼的保險箱，不能上網.env.local，AI 被設定成讀不到

AI 開發工具（兩個網站都用）

Claude Code兩班都教猜猜看：程式是誰寫的？
會讀檔、寫程式、跑指令的 AI 助手兩個網站的程式都由它寫，店主負責決定與驗收
CLAUDE.md兩班都教猜猜看：怎麼讓 AI 每次都守規矩？
寫給 AI 看的班規例如「錢一律後端算」「先說要改哪裡，等同意再動手」
Git 存檔兩班都教猜猜看：改壞了怎麼回到昨天？
遊戲的存檔點，改壞可以讀檔每完成一件事 commit 一次，約 25 個存檔
權限設定進階猜猜看：有什麼是 AI 絕對不能碰的？
硬性規定 AI 不能碰的東西.claude/settings.json：禁讀密碼檔，push 前要先問
規格文件進階猜猜看：大功能動工前要先做什麼？
動工前先寫清楚要做什麼優惠碼的 PRD（需求）、SDD（設計）、TASKS（分步）、CHECKLIST（驗收）
檢查腳本進階猜猜看：怎麼確定修好的東西不會再壞？
自動幫你檢查有沒有壞掉的小程式超賣、優惠碼名額、密碼外洩等 8 支檢查
圖二

和 AI 一起做網站的流程

這是整堂課最重要的一張圖。網站不是一句「幫我做電商網站」就完成的，而是先定規矩，再一次做一小件，每件都自己點過才存檔。

課程路線

基礎班與進階班

商店那一半要註冊 Neon、Vercel、GitHub、綠界等多個帳號，部分服務有年齡限制，金流概念對國中生也偏重。建議先做基礎班，進階班給高中或社團。

基礎班 我的 3D 小島商店

  1. 寫自己的 CLAUDE.md 班規
  2. 請 AI 規劃小島和檔案分工
  3. 做出地形、建築、可旋轉的鏡頭
  4. 建立 JSON 商品資料，點建築跳出圖卡
  5. 加「假購物車」：用瀏覽器本機儲存記住買了什麼，結帳只顯示「訂單完成」
  6. 用 Netlify 拖曳上線，互相逛同學的島

需要瀏覽器、Python 和 AI 工具；雲端帳號只要 Netlify 一個。

進階班 真的能下單的店

  1. 從範本商店開始，改成自己的店名與商品
  2. 連上 Neon 資料庫，跑 npm run db:setup
  3. 看懂圖三：為什麼錢要在後端算
  4. 用 PRD → SDD → TASKS 的方式加一個功能（例如優惠碼）
  5. 寫檢查腳本，確認不會超賣
  6. 部署到 Vercel，和基礎班的小島互連

需要 Node.js、Git、GitHub、Neon、Vercel 帳號。密碼一律由學生自己填，不貼給 AI。

提示詞範本

每一步怎麼對 AI 說

正面是這一步要做的事，先讓學生自己寫一句提示詞，再翻面對照範本。好的提示詞有三個部分：要做什麼、限制是什麼、做完要怎麼回報。

①

先定規矩

最重要

規矩寫在檔案裡，AI 每次都會讀，不用每次重講。

先想想：你希望 AI 遵守哪四條規矩？

① 先定規矩・範本
我要做一個賣果醬的模擬商店網站，給國中生學習用。請先幫我寫一份 CLAUDE.md 工作守則：
1. 用繁體中文回答，技術名詞第一次出現要用一句話解釋
2. 動手前先說要改哪些檔案，等我同意再做
3. 一次只做一件事，做完告訴我要在瀏覽器點哪裡檢查
4. 沒實際檢查過的，不可以說已經完成
②

先規劃，不寫程式

先看計畫再決定，比做完才發現方向錯省很多時間。

先想想：要怎麼叫 AI「先別寫」，又要它告訴你什麼？

② 先規劃・範本
我想做一座 3D 小島當商店入口，島上有工坊、廣場、果園，點建築會跳出果醬介紹。
先不要寫程式。請告訴我：需要哪些技術、檔案怎麼分、要分幾步做完。
限制：只用 HTML、CSS、JavaScript 和 Three.js，不要安裝任何套件。
③

資料和程式分開

以後改商品文字只要改資料檔，不會不小心弄壞程式。

先想想：一款果醬需要記下哪些資料？

③ 資料和程式分開・範本
請建立 content/jams.json，放 6 款果醬的名稱、產地、一句介紹、代表色。
網頁從這個檔案讀資料，之後我改文字就不用碰程式。
④

一次加一個功能

說清楚「現在只做這件」，並要求 AI 告訴你怎麼驗收。

先想想：做完之後，你要 AI 告訴你什麼？

④ 一次加一個功能・範本
現在只做一件事：點小鍋工坊時，右邊跳出面板，顯示全部果醬圖卡。
做完告訴我：要點哪裡、應該看到什麼。
⑤

出錯時給證據

只說「壞了」，AI 只能猜。貼上完整錯誤訊息，它才知道問題在哪。

先想想：除了「壞了」，還要告訴 AI 哪兩件事？

⑤ 出錯時給證據・範本
我點工坊沒反應。這是瀏覽器 F12 主控台的紅字：（貼上錯誤訊息）
請先說你判斷的原因，再改。
⑥

安全觀念

進階

搭配圖三。讓學生自己想到「如果有人改價格會怎樣」。

先想想：如果有人在瀏覽器把價格改成 1 元，會發生什麼事？

⑥ 安全觀念・範本
結帳時總金額是前端算好送到後端的，這樣安全嗎？
如果有人在瀏覽器改成 1 元會怎樣？請用國中生聽得懂的話解釋，再改成由後端重新計算。
⑦

上線

上線前讓 AI 列檢查清單，避免把密碼一起傳上去。

先想想：上線前要檢查哪些東西？

⑦ 上線・範本
我要把這個資料夾放到 Netlify。請一步一步告訴我要點哪些按鈕，上線前要檢查什麼。
圖三・進階班

下單到付款，錢在哪裡算

客人的瀏覽器只送「買了哪幾樣、各幾罐」。價格、運費、折扣都由商店後端從資料庫重新算。訂單要等綠界送來付款通知，並確認簽章正確、沒處理過，才會變成「已確認」。

投影片收尾

和 AI 合作的五個好習慣

先規劃再寫
看過計畫才讓 AI 動手例：「先不要寫程式，告訴我要分幾步。」
一次一件事
小步做，壞了才找得到原因例：這間店的優惠碼拆成 3 個存檔完成。
自己點過才算完成
AI 說好了不等於真的好了例：驗收清單記下 31 項通過、1 項不通過、10 項未檢查。
錯誤訊息完整貼上
給證據，不要讓 AI 猜例：F12 主控台的紅字整段複製貼上。
密碼不給 AI、不上網
放在環境變數，自己填例：這間店設定成 AI 讀不到 .env.local。
