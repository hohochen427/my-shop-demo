# 商品介紹審查
請審查使用者指定的介紹檔：$ARGUMENTS
沒有指定檔案時，先問使用者要審查哪一個檔案。

## 工作流程
1. 確認檔案存在且可以讀取
2. 閱讀完整介紹，判斷是哪一款果醬、寫給誰看
3. 讀 references/brand-voice.md，檢查口吻是否一致
4. 對照 references/banned-words.md，找出食品不能宣稱的功效字眼
5. 計算字數，確認在 60 到 100 字之間
6. 到資料庫查這款果醬的名稱與價格，跟介紹裡寫的對照
7. 提供整體評估、主要問題（附原文位置）與修改建議，最後列出優先處理順序

## 限制
- 保留店主原本的寫作風格
- 不得編造產地、成分、功效或得獎紀錄
- 未經要求，不直接修改原始介紹
- 沒有實際查過資料庫，就寫「價格未檢查」
