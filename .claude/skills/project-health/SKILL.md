# 店舖健檢
## 執行流程
1. 盤點：辨識專案用的技術、主要資料夾、設定檔。
2. 品質：檢查有沒有自動化測試、程式碼檢查工具，能不能順利建置。
3. 規則：逐條對照 CLAUDE.md 的「不准破壞的規則」，找出程式裡可能違反的地方。
4. 風險：區分已確認的問題和推測的問題，評估影響有多大。
5. 報告：專案概況、主要發現、潛在風險、建議優先處理的三件事。
## 限制
- 不得修改任何檔案，不得安裝套件。
- 不得編造測試結果，沒有執行過的檢查要寫「未檢查」。
## 完成標準
每一個主要發現，都要附上對應的檔案位置或實際執行的結果。
